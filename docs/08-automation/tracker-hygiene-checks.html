Issue Tracker Hygiene Checks

Skill: Data quality for delivery reporting · Competency: Keeping the data behind reports and automation trustworthy

Reports and automation are only as good as the data underneath them. Run these checks weekly, ideally automatically, and send the results to item owners.

CheckRule (example)Why it matters
Missing ownerActive item with no assigneeNobody is accountable
Missing priorityDefect without a prioritySLOs can't be calculated
Missing target dateRelease-bound item with no planned dateReadiness gates can't evaluate it
Stale item"In progress" with no update for 14+ daysA hidden blocker or abandoned work
Status mismatchMarked done, but linked defects are still openFalse reporting
Done without releaseMarked done, but no release date or versionInflated delivery numbers
OrphanStory not linked to an epic or goalUntraceable work
Missing componentNo product/component fieldBreaks per-area reporting
Date driftTarget date changed 3+ timesA signal about planning quality

Output format

Group findings by owner, so that each person gets one list of their own fixes:

@Owner: 3 items need attention
• 2 stale "In progress" items (no update in 14+ days)
• 1 defect missing a priority

Tips

  • Track a hygiene score (% of items passing every check) over time, and celebrate improvement.
  • Fix the process upstream with required fields and workflow validators, rather than chasing the same gaps every week.
  • Show hygiene exceptions on dashboards instead of quietly excluding them (see the dashboard guide).
